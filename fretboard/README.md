# Fretwise

A standalone guitar sight-reading and fretboard trainer. Open `index.html` through an HTTP server (ES modules require HTTP) or use the published HTTPS page. Optional accounts use a dedicated Supabase project; guest practice works without signing in. The trainer does not use the inventory app or external audio services.

## Practice

- The sticky section navigation links **Practice**, **Notes & goals**, **Sound**, and **My progress**. Playback and self-checks are grouped with the score; the session timer, duration goal and Finish button sit together below it. Note selection, rhythm, target tempo and recommendations share the setup panel. The sound studio groups metronome, drums, backing and reference guitar controls, with master volume above them. On phones and tablets the panels stack, and each section stays accessible through the navigation. Keyboard links do not trigger playing shortcuts.
- Defaults to standard tuning, strings 1–6 and frets 0–21. Choosing C includes every available C3, C4, C5 and C6. Register and fret/string filters can narrow practice.
- **View full note map** previews any of the 12 notes across all six strings and frets 0–21, independently of exercise filters. Filter by exact sounding octave, compare classical staff examples, and select a colored fretboard dot or circled-string/fret chip to connect that location with the notation. Each card labels sounding and written pitch; selecting a location adds its circled string to the staff when that pitch has multiple locations. A reference tone respects microphone/headphone muting. The recommended next note can be previewed before adding it. Opening the map pauses playback and marks an in-progress phrase assisted; it does not change the practice setup or award progress.
- Four-bar phrases of 4/4 in standard guitar treble notation, with count-in, moving playhead, quarter/half/whole notes, editable tempo, looping and a wait-for-input mode. The sheet advances one line at a time: two bars per line on desktop, one on phones. Play the top line and read ahead below. At each line boundary the lower line moves up and the next appears underneath, including across looping phrase boundaries. Previewed pitches and assigned strings stay unchanged; bar numbers continue through the session. Staff spacing stays fixed for the selected range and note palette. With looping off, the last line shows an end-of-phrase message below, then the final two lines return for review. Restarting or changing the practice setup starts again at bar 1.
- **Practice view** dedicates the available screen to both music lines and touch controls. Play opens this view automatically on phones; it can also be opened with the Practice view button. The sheet fits without horizontal swiping, with larger string instructions on short landscape screens. Play/pause, restart, playback tempo, I played it and Skip stay within reach. Exit practice (or Escape) pauses and returns to setup. Rotation changes the layout without regenerating notes, resetting playback, or losing the queued preview. Microphone mode keeps the manual self-check disabled in this view too.
- The metronome defaults to recordings of a real pendulum metronome, alternating its tick and tock at the score tempo. It has its own volume, an optional first-beat accent, a digital alternative and a four-beat preview. The count-in uses the chosen sound even when the ongoing metronome is off. It follows transport and microphone/headphone muting. If recordings cannot load, a visible status explains the digital fallback; Preview retries the download. See `samples/metronome/README.md` for source and license.
- Note names and frequencies are **sounding pitches**. Guitar staff notation is written an octave higher, shown with an 8 below the treble clef. Accidentals are spelled by the selected scale, reset per bar, and cancel with naturals where needed.
- **Hear target** and the note map use 723 real guitar recordings from Meta Creative Audio: steel-string acoustic or nylon/classical, with three selectable playing touches. The selected string chooses the recording, so equivalent pitches on different strings retain their distinct timbres. Full natural decay is preserved, with a short fade on interruption. Guitar level is separate from master volume. The map's voice/touch selectors share the saved settings under Sound → Your reference guitar.
- Guitar samples load one at a time on demand; the entire 40.8 MiB library is never downloaded at startup. Missing or upper-fret positions use the nearest recorded pitch on the same string, with the adjustment disclosed in the playback status. Download/decoding failure offers Hear-to-retry and leaves manual practice available. Closing the map, changing selection, muting, pausing or starting practice cancels pending previews. See `samples/guitar/README.md` for exact coverage, source formats and licenses. These are reference-note previews; the tonal drone/bass backing remains synthesized.
- Circled string numbers sit immediately above or below each notehead in the score and note map when the exact pitch has multiple locations. Pitches with only one location across all six strings and frets 0–21 (such as C6) omit the number, independently of practice filters. They are classical guitar location instructions. The pitch plus the assigned string fixes the fret. Equivalent pitches on other strings do not satisfy a fretboard answer.
- Manual self-checks, interactive fretboard checks and optional local microphone pitch/octave/onset detection. The microphone cannot verify physical string choice. It requires HTTPS/localhost and permission; failure leaves manual mode usable. Microphone mode mutes all app audio to prevent feedback, unless the user enables the headphones option. With headphones, metronome, count-in and backing remain audible during microphone checking. Play single notes, damp sustain between repeated pitches, and expect device-dependent latency.
- **Playback tempo** sets the current speed of the score, metronome, drums and generated backing. **Target tempo (goal)** is the separate speed to reach for progression; changing it does not change playback. Both accept 1–180 BPM and are saved as separate settings, with account sync when signed in. At 1 BPM, each beat lasts a minute, including each of the four count-in beats; use Wait for me for untimed practice.
- Start slow, then raise the playback tempo. At or above the chosen target BPM, each exact pitch needs at least two clean, unaided passes and four correct occurrences in the chosen rhythm. Manual milestones are self-rated. Wait mode and hinted/revealed answers do not earn milestones. This is practice evidence, not a guarantee of permanent recall or physical-position mastery.
- Recommendations first identify weak/unlearned exact pitches, then choose a nearby unused scale pitch class. Adding a pitch class adds all its available selected octaves. Optional automatic progression adds it between phrases, after any phrase already prepared for the read-ahead view, so notes visible on the sheet never change unexpectedly.
- A tonic/fifth drone or bass groove follows key and tempo. Local audio files loop unchanged; no automatic key detection, transposition or tempo stretching is claimed. The chromatic family warns that a fixed-key accompaniment may clash.
- Recorded acoustic drums follow the score's BPM in pop, rock, shuffle and half-time grooves. Kick, snare, closed/open hats, three toms, ride and crash use 24 real recordings with alternate takes and velocity layers. Optional fills finish every four bars. Drum level is independent of the backing, under the master volume. Preview plays four bars without starting practice. Drums start after the count-in, stop with the transport, and respect microphone/headphone muting. The swung subdivision in the shuffle accompanies the score; written quarter/half/whole notes keep their normal beat lengths.
- Samples are a compact CC0 subset of Karoryfer's Big Rusty Drums, mixed with the original room recordings. They are fetched on demand from this site's own assets (about 18.2 MiB); no account, subscription or external audio service is required. See `samples/acoustic/README.md` for source, license and rebuilding instructions. Failed loading offers retry or drums-off practice.
- **Profiles** give each person a username, email/password login, separate settings, exact-pitch progress and session history. Confirm the signup email, then sign into the same account on another device. The account dialog includes username editing, password changes, recovery, manual sync and sign-out on this device. Guest history remains separate; a one-time import adds it to the chosen account while preserving that account's settings. Switching accounts saves the outgoing session and clears its active score, microphone and local backing file.
- **My progress** shows a Monday–Sunday weekly summary with a daily time chart, days practiced, sessions, checked notes and accuracy (including unplayed notes and marked self-checks). Browse previous weeks and individual sessions with their duration, playback tempos and exact pitches studied. Sessions save every five seconds during playback and on pause or page leave, even without pressing Finish session. Resume updates the same session instead of counting it twice; finishing or reloading starts a new one. Active time includes the count-in but excludes pauses, and splits across local calendar days at midnight, including daylight-saving changes. Historical records without daily details use their saved date. The latest 365 sessions are retained.
- Setup, session summaries and pitch progress are cached in browser localStorage. Signed-in practice also syncs to private, per-user database records; offline saves retry on reconnect, focus and a 15-second refresh. Remote settings wait until playback is paused. Revision conflicts merge new practice instead of overwriting it, newer checkpoints replace older copies of the same session, and save receipts prevent double counting after lost responses. The displayed status distinguishes synced work from work waiting on a connection. Microphone audio is processed transiently and is never recorded or transmitted. User audio files are used through local object URLs. Audio downloads come from the site's own bundled guitar, drum and metronome assets.

## Run and verify

Serve the repository with a local static server and open `/fretboard/index.html`.

```
npm test
```

Browser tests use the existing Playwright dependency. Set `PLAYWRIGHT_BROWSERS_PATH` to the installed browser directory where required. Tests cover octave separation, harmonic-rich pitch detection, scale spelling, coverage, string constraints, clean-pass progression, transport, responsive layout, permission denial and microphone input simulated through a real AudioContext. Note-map checks verify all 132 physical string/fret positions across the twelve pitch classes, staff placement and enharmonic octaves, octave filtering, keyboard selection, responsive layout, independent practice settings, recommendation preview, assisted phrases and microphone-safe reference tones. Drum checks validate every bundled recording against its manifest, decode and render real samples through Web Audio, check alternate takes and hi-hat choking, and exercise preview, count-in, loop timing, pause/resume, microphone muting, failed downloads, retry and cancellation. Metronome checks render the recorded clicks, verify alternating samples and accent strength, and exercise four-beat preview timing, saved controls, count-in rules and disclosed fallback/retry.

References: [Yamaha guitar notation and tuning](https://www.yamaha.com/en/musical_instrument_guide/classical_guitar/play/play002.html), [MDN microphone requirements](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia).
